当光线穿过非均匀介质或弯曲的透光表面（如水面波纹或水晶棱镜）时，光线的折射率不再是恒定值。由于斯涅尔定律（Snell's Law）以及柯西色散公式（Cauchy's dispersion equation），不同波长的光线会以微小差异的角度弯折，在投影面上形成高度聚焦的明亮条纹网络——这就是**焦散（Caustics）**与**色散（Dispersion）**。

在这篇文章中，我们将抛开沉重的光线追踪光子映射（Photon Mapping），转而利用**域扭曲（Domain Warping）**和**波长相移（Phase Shift）**技术，在实时帧率下还原这种令人惊叹的光学质感。

<Callout type="optics" title="为什么波长分离至关重要？">
在真实物理世界中，可见光的波长在 380nm（紫光）到 740nm（红光）之间。高折射率介质对短波长光线具有更强的偏折能力，因而在焦散线边缘总伴随着彩虹般的色散光晕。
</Callout>

## 1. 简谐重叠与域扭曲

要模拟流动起伏的焦散线网，最直接且 GPU 极其友好的算法是结合多层带相位的旋转正弦波：

```glsl
float causticPattern(vec2 uv, float time, float offset) {
  vec2 p = uv * 3.5;
  for (int i = 1; i < 5; i++) {
    float fi = float(i);
    p += vec2(
      sin(p.y * 1.5 + time * 0.4 + offset) * 0.4,
      cos(p.x * 1.5 + time * 0.35 + offset) * 0.4
    );
  }
  float c = sin(p.x + p.y) * cos(p.x - p.y);
  return abs(c);
}
```

通过在循环中将坐标向量 `p` 自身作为三角函数的输入，我们创造出类似非线性流体折射的扰动场。

## 3. 颜色映射与高动态范围（HDR）处理

传统的 RGB 叠加很容易在亮斑处直接截断为纯白（`(1.0, 1.0, 1.0)`），失去光线的层次感。我们采用非线性幂次增强配合 ACES 色调映射，保留高光中心能量感的同时呈现丰富的色散渐变：

```glsl
// 高次幂强化焦线对比度
r = pow(r, 4.0);
g = pow(g, 4.0);
b = pow(b, 4.0);

vec3 colR = vec3(0.95, 0.32, 0.55) * r * 1.4;
vec3 colG = vec3(0.22, 0.85, 0.98) * g * 1.5;
vec3 colB = vec3(0.58, 0.35, 1.00) * b * 1.8;

vec3 finalColor = colR + colG + colB;
```
